
# 📝 Guide de Notation Markdown

## Titres

```markdown
# Titre niveau 1
## Titre niveau 2
### Titre niveau 3
#### Titre niveau 4
##### Titre niveau 4
```

---

## Texte en gras, italique, barré

```markdown
**gras**
*italique*
~~barré~~
```

---

## Liens

```markdown
[Texte du lien](https://exemple.com)
```

---

## Image

```markdown
![Texte alternatif](https://url-de-l-image.com/image.png)
```

---

## Listes

### Liste non ordonnée

```markdown
- Élément 1
- Élément 2
  - Sous-élément
```

### Liste ordonnée

```markdown
1. Premier
2. Deuxième
```

---

## Code

### En ligne

```markdown
Voici un `mot` en code.
```

### Bloc de code

```javascript
function hello() {
  console.log("Hello world");
}
```

---

## Bloc de citation

```markdown
> Ceci est une citation.
```
